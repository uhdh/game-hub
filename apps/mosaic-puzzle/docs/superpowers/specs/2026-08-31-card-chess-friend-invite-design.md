# 카드체스 친구 초대 설계

## 목표

링더벨의 기존 WebRTC 초대 링크 방식을 재사용해 카드체스 1대1 친선전을 제공한다. 온라인 승패는 카드체스 리더보드에 반영하지 않는다.

## 동작

- 방장이 P1, 초대받은 친구가 P2를 맡는다.
- 방장은 `CC` 접두사가 붙은 초대 링크를 만들고 친구에게 전달한다.
- 방장이 초기 상태를 한 번 생성해 전송하며 이후 양쪽은 같은 액션을 카드체스 엔진으로 적용한다.
- 각 사용자는 자신의 카드와 말을 화면 아래쪽에서 보고 자신의 턴에만 조작한다.
- 온라인에서는 AI, 난이도 변경, 무르기, 새 게임과 리더보드 기록을 사용하지 않는다.
- 잘못된 액션, 상태 불일치 또는 연결 끊김은 안내하고 경기를 중단한다.

## 범위

기존 `ring-the-bell-p2p.js`와 신호 테이블을 그대로 사용한다. 카드체스용 별도 Supabase 테이블이나 새 통신 계층은 만들지 않는다.
